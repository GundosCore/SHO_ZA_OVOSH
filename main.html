О проекте

Кратко: данная нейросеть способна распознавать овощ по фотографии

Что это за проект

Как это работает?

  • Пользователь загружает фотографию в веб-интерфейс нейросети.
  • Нейросеть анализирует изображение и распознаёт, что за овощ на фото, в процентном соотношении.
  • Результат выводится в удобном формате: на интерфейсе высвечивается список возможных вариантов: 4 самых вероятных овоща (ответ будет более-менее однозначным) и самый !вероятный.

Применение

Применение данного рода программы связанно в первую очередь с усиленным дообучением нейросети поскольку команда проекта не имеет достаточных ресурсов для полноценного создания более мощной модели.


После выполнения данного условия нейросеть можно будет использовать следующим образом:

Применение в супермаркетах и других магазинах. Можно внедрить нейросеть в кассы самообслуживания, настроить под ассортимент магазина и при взвешивании весовых товаров камера будет определять продукт. Данная функция как упростит покупателю поиск нужного товара на весах, так и в какой-либо степени защитит от мошенников, пытающихся купить более дорогой товар, пробивая его как дешёвый

Кроме того, разумеется, нейросеть так же подходит для клиентского пользования, то есть "загуглить", что это на фото



Польза и преимущества

  • Экономия времени: Покупателю больше нет необходимости вручную искать товар без штрихкода, это добавляет как удобство, так и скорость покупок.
  • Экономия пространства: В связи с ускорением покупок клиентом, касс самообслуживания будет нужно в целом меньше, что освободит драгоценное пространство под другие нужды.
  • Экономия финансов (предположительная): Оснастить простой камерой и программой кассу самообслуживания будет предположительно дешевле, чем ставить ещё одну.
  • Работает офлайн: Модель представляет собой уже обученную нейросеть, для её работы нет необходимости в подключении к интернету.

Разработка

Поскольку для точного определения овоща необходимо использовать свёрточную нейросеть, командой была не обучена с нуля, а дообучена настроенная под распознавание изображений нейросетевая модель MobileNetV2.


Модели был предоставлен датасет из 100+ фотографий на каждый овощ, было проведено обучение при помощи некоторых библиотек на языке python. Их названия и применение описаны ниже:

  1. TensorFlow: Основная библиотека для создания и обучения нейросетей. Включает в себя реализацию MobileNetV2 и все необходимые слои.
  2. Keras: Высокоуровневый API TensorFlow, использовался для построения модели, генераторов данных и компиляции сети.
  3. NumPy: Использовался для операций с массивами данных, необходимых при предобработке изображений.
  4. Matplotlib: Применялась для визуализации процесса обучения (графики точности и потерь).
  5. Pillow (PIL): Используется для загрузки и обработки изображений в Python.

Обучение нейросети:

Обучение модели происходило в два этапа на платформе Google Colab.

  • Этап 1: Обучение "головы" (Head Training)
    • Базовая модель MobileNetV2 была загружена с предобученными весами ImageNet, но её слои были заморожены.
    • Добавлены новые слои: GlobalAveragePooling2D, Dropout (0.4), Dense (256, ReLU), Dropout (0.4), и Dense (число_классов, Softmax).
    • Модель обучалась в течение 15 эпох с оптимизатором Adam (learning rate = 1e-4).
    • Для улучшения обобщающей способности использовалась аугментация данных (повороты, сдвиги, зум и т.д.).
    • Применялись Callbacks: EarlyStopping (patience=4) и ReduceLROnPlateau (factor=0.3).
  • Этап 2: Дообучение (Fine-Tuning)
    • После первого этапа была разморожена верхняя половина слоёв MobileNetV2 (примерно половина от общего числа).
    • Модель снова обучалась в течение 15 эпох, но с меньшим learning rate (1e-5), чтобы не "сломать" уже полезные признаки в нижних слоях.
    • Этот этап позволил модели адаптироваться к специфике нашего датасета.

После завершения обучения модель была сохранена в формате .h5 и используется в backend-части приложения.


Backend

Backend приложения реализован на Python с использованием веб-фреймворка Flask. Его основная задача - принимать изображения от веб-интерфейса, обрабатывать их и возвращать результаты распознавания от нейросети.

  • Flask: Создаёт веб-сервер и определяет API-эндпоинты. В данном случае, используется один маршрут - /predict методом POST.
  • Flask-CORS: Обеспечивает корректную работу с веб-интерфейсом, разрешая кросс-доменные запросы (CORS).
  • TensorFlow/Keras: Используется для загрузки обученной модели (vegetable_finetuned.h5) и выполнения предсказаний (model.predict()).
  • Pillow (PIL) и NumPy: Применяются для открытия, изменения размера и преобразования изображения в формат, пригодный для подачи в нейросеть.

Когда пользователь загружает изображение в интерфейсе, оно отправляется на сервер. Там происходит следующий процесс:

  1. Сервер проверяет, был ли загружен файл.
  2. Изображение читается в формате байтов.
  3. Функция preprocess_image открывает изображение, конвертирует его в RGB (если нужно), изменяет размер до 224x224 пикселей, применяет препроцессинг, необходимый для MobileNetV2, и добавляет размерность батча.
  4. Обработанное изображение подаётся в нейросеть (model.predict()), которая возвращает массив вероятностей для каждого класса.
  5. Сервер сортирует 5 самых вероятных классов и возвращает их названия и вероятности в формате JSON.
  6. Этот JSON отправляется обратно во frontend, где результаты отображаются пользователю.

Сервер запускается локально и слушает порт 5000, обеспечивая автономную работу всего приложения.


Frontend

Frontend реализован с помощью HTML, CSS и JavaScript и представляет собой интерактивный веб-интерфейс, который взаимодействует с backend-сервером.

  • HTML: Создаёт структуру страницы, включая навигацию, область загрузки изображений, панель с поддерживаемыми овощами и область отображения результатов.
  • CSS: Отвечает за визуальное оформление, адаптивность и удобство использования интерфейса.
  • JavaScript: Обеспечивает динамическое поведение страницы, включая переключение между разделами, загрузку изображений (в том числе drag & drop) и отправку данных на backend.

При загрузке изображения пользователем (через кнопку или drag & drop) происходит следующее:

  1. Изображение читается в браузере с помощью FileReader и отображается в центральной области интерфейса.
  2. Файл автоматически отправляется на backend (локальный сервер Flask на http://localhost:5000) с помощью асинхронного запроса fetch с методом POST.
  3. После получения JSON-ответа с результатами от нейросети, функция updateResults обновляет правую панель, отображая 5 самых вероятных классов и их вероятности.

Таким образом, интерфейс обеспечивает простое и интуитивно понятное взаимодействие с нейросетью, скрывая сложные технические детали от пользователя.
